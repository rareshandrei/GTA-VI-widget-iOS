# GTA VI countdown widget

A medium iOS home screen widget showing the days until GTA VI releases on
**19 November 2026**, outlined over the Jason & Lucia artwork.

Runs on [Scriptable](https://scriptable.app) (free) — no Mac, no Xcode, no
Apple Developer account, nothing that expires.

## Setup

1. Install **Scriptable** from the App Store.
2. Tap **+** to create a new script, name it **GTA VI**.
3. Paste in [`install.js`](install.js) and run it once while online.
4. Home screen: long-press → **+** → **Scriptable** → **medium** → add.
5. Long-press the widget → **Edit Widget** → *Script* → **GTA VI**.

That's it. The script pulls `widget.js` from this repo and caches it, so it
keeps working offline and updates itself when this repo changes.
